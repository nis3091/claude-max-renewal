## 续费前搞清楚：额度怎么重置

续费本质上买的是额度，重置机制值得弄明白，免得续完发现“怎么额度还是不变的”。

- **5 小时会话限额**：每 5 小时重置一次。Max 5x 是 Pro 单次会话额度的 5 倍，20x 是 20 倍。
- **每周限额**：跨所有模型累计。重置时间是系统分配给你账户的固定时间——跟你什么时候续费、什么时候开始用都没关系，每个周期直接给满额度。
- **Fable 单独周限额**：Max 套餐对 Fable 模型另设周用量上限，官网价格页标注为每周限额的 50%。
- **重置时间查询**：在设置的 Usage 页面能看到下次重置时间。如果你拿到 limit resets，可以直接把 5 小时限额或每周额度拉满。

另外，平台保留按需增加周/月上限、或对特定模型和功能限流的权利，这条写在条款里，属于“知道就行”的部分。

## 续费时顺便调套餐：扣费规则

不是所有人都单纯续费，不少人会趁续费调整档位，这里的规则有几处容易踩坑。

**从低档升高档**（比如 5x 升 20x）：本计费周期剩余时间按比例补差价，不会重新计一个整月。如果领过每月 API 额度，会先按比例拿到新档位的额度，之后每个周期按新金额发放。

**从年付 Pro 转到 Max**：如果年付套餐的剩余余额高于 Max 价格，差额会以账户额度返还，抵扣以后的订阅费用。坑在这里——两次购买的账单地址必须一致，否则拿不到返还，只能取消 Pro 等订阅到期后重新订。

**通过 Google Play 升级**：逻辑不一样，按新套餐全价扣费，旧套餐没用完的价值折算成新套餐的额外天数，所以你的续费日会比一个整月晚几天。

## 10 月起续费多了一项权益：每月 API 额度

10 月 7 日之后订阅或续费 Max，会多一块实打实的东西：每月 API 额度。

- Max 5x：每月 100 美元
- Max 20x：每月 200 美元
- Team 计划：标准席位每席 20 美元、高级席位每席 100 美元，全团队合并成一个池，上限 500 美元

三条关键规则：**不结转**，每个计费周期结束清零；覆盖范围是 Claude API、Managed Agents、Agent SDK 和 playground，交互式 Claude Code、Claude 应用内的额外用量、以及 Bedrock / Google Cloud / Microsoft Foundry 上的用量都不算；额度用完后 API 请求会暂停，等下个月的额度到账，不会转头扣你的订阅。

领取流程：登录 Claude 网页版，进 Settings > Billing，在 API credits 区块绑定一个 Claude Console 组织。注意一个计划只能绑一个 Console 组织，而且绑定后自己改不了，绑之前想清楚要在哪个组织里用。新订阅用户要满 7 天才能领，额度以 Promotional credits 的形式出现在 Console 里。这次权益是分几天逐步上线的，后台暂时没看到入口的话，过几天再查。

这块额度值不值钱，取决于你用不用 API。按官网定价页 Sonnet 5 的价格（输入每百万 token 2 美元、输出 10 美元）粗算，一次 2 万输入加 2 千输出的典型 agent 调用大约 0.06 美元，200 美元额度能覆盖三千多次。如果你每月 API 按牌价本来就要花 200 美元以上，Max 20x 相当于把前 200 美元打了回来；花不到这个数，多出来的部分就只是数字好看。

最后一个小陷阱：赠送额度会先于自己充值的额度被消耗，而自动充值只盯着你充值的余额。不需要的话，先把 auto-reload 关掉。
